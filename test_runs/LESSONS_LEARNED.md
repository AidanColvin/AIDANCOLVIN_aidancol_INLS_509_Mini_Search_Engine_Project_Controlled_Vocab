# Lessons learned (cumulative; append, never overwrite)

## Cycle 1 — run 2026-09-23_0648 (baseline) → fixes in the next commit

Read before every Phase 3 cycle. Pattern classes are the pack's list.

### What went wrong, once

1. **One parser defect hid everything.** All 244 entries came back "not found". `parse_entry` removed the strength and frequency but left `Brand (generic) = total` in the name. So `"Ambien (zolpidem) = 10 mg/day"` went to the dictionary and to RxNorm, and nothing downstream ever ran. General fix: split off `= total`, read the parenthesized generic as the drug and the brand as a fallback, and resolve by the written ingredients before fuzzy names (`split_stated_total`, `split_brand_and_generic`, `resolve_written_generic`, `resolve_ingredient_only`).
2. **Label-tag rules alone cannot reach major-level recall.** The earlier harness found 29 hits in 196 even with names resolved, because "both labels mention QT" says nothing about CYP3A4, P-gp, or a dose cap. General fix: a class-level rule table (`data/reference/interaction_knowledge.json`, 90 rules). Each rule has named class members, a grade, a mechanism, an action, a rulebook row, sources, and a build-time search for the FDA label sentence that states it (`knowledge_evidence.py`).
3. **Counting ingredients instead of medicines.** Adderall's amphetamine plus dextroamphetamine counted as two serotonergic drugs, and Zoloft plus generic sertraline counted as two. Fix: `molecule_count` clusters by entry and by shared ingredient.
4. **Label-only groups over-flag.** A label mentioning QT is not a QT-prolonging drug (omeprazole in L22 and L30). Fix: where a class rule covers the drugs, the rule's grade stands and the label sentence becomes its evidence. Uncovered label groups drop to grade A, which never counts toward the B-or-above control rule.
5. **The totals must be per ingredient across entries.** That means combination components, units, named-day and weekly schedules, as-needed maximums, and MME (`totals.py`).
6. **Grader lessons, which are not app changes.** Only the grader was changed for these:
   - The key's category name itself (for example "efficacy loss") counts as naming the category.
   - "Three or more drugs" counts drugs, not the ingredients inside one combination product.
   - A should-not-flag ingredient inside a product whose flagged interaction is an expected item (Truvada's emtricitabine) is not a false positive.
   - Any 2xx status counts as a working link: PubMed answers scripted requests with 203.
