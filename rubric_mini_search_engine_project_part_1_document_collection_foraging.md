# Mini Search Engine Project Part 1: Document Collection Foraging

Pick a document collection from a domain that interests you. You will use this document collection as a case study in this semester.

Each document in the collection should have at least one field where text information is key. A list of document collections selected by students in previous semesters can be found here. An example document collection can be found here.

For your chosen collection, please briefly describe:

* **What is the collection about?**
* **Who will most likely be interested in searching this collection?**
* **Does the collection contain more than 50 documents?** If so, and if you have to choose no more than 50 documents from it, how would you narrow down the collection (e.g., can you take a random sample, use keyword search, metadata-based sorting or filters, etc.)?
