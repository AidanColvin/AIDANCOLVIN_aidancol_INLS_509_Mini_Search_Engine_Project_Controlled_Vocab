# Open questions

Each entry records an ambiguity, the choice made, and the alternatives. Nothing here stopped the build.

## Phase 0

1. **Filter order and the empty `openfda` object.** Filter 1 (product type) reads `openfda.product_type`, so a label with no `openfda` block fails filter 1 before filter 2 is reached. The live probe also found `openfda` present but empty (`{}`) in 380 of 2,883 records in one partition. Choice: filter 2 tests for a non-empty `openfda` object; the stats file still reports the count after each numbered filter in the prompt's order, plus an extra count for labels that have `openfda` but no `substance_name`. Alternative: treat an empty dict as "has openfda", which would keep labels that can never form an ingredient set.
2. **Labels with `openfda` but no `substance_name`.** Example: Zyprexa Relprevv (set_id 11544cba-64a9-49cb-8d74-da228053b252). Such a label cannot form an active-ingredient set, so filter 3 cannot place it. Choice: drop it and count it under `after_filter_2b_has_substance_name`. Alternative: key it by `generic_name`, which is not what Section 2 defines.
3. **Commit-message hook timing.** Section 9.5 adds the hook in Phase 1 "before the first commit", but Phase 0 also commits. Choice: the hook, `tests/test_style.py`, and `tests/test_no_attribution.py` were added before the Phase 0 commit, which is the earliest reading of both rules.
4. **`self` and `cls` type hints.** Section 8 requires a hint on every parameter. Python methods conventionally leave `self` and `cls` unannotated, and Vercel's Python handler and `html.parser` subclasses require methods. Choice: `tests/test_style.py` exempts only an unannotated first parameter named `self` or `cls` on a method; every other parameter must be annotated. Module-level functions are used everywhere else.
5. **Attribution scan scope.** The user's own write-ups contain the forbidden names in their AI-use statements, and Section 8 exempts "my own write-up files". Choice: `tests/test_no_attribution.py` scans every tracked and untracked non-ignored file except `notes/`, `rubrics/`, `document_collection_part_1/`, `MiniVocab_Aidan_Colvin_aidancol.md`, and `LICENSE`, skipping binary suffixes such as `.zip`. The Section 12 bundle zip will contain a copy of the build prompt, which is the user's own document; the zip is binary and is not scanned.
6. **Flexeril is not in openFDA.** The API returned no label with brand name FLEXERIL on 2026-09-21, so the local name dictionary cannot map "Flexril" to Flexeril. Choice: the RxNorm fallback resolves "Flexril" to the obsolete brand concept 224954 through approximateTerm, then to cyclobenzaprine (rxcui 21949) through getRxcuiHistoryStatus, because getRelatedByType is Active-scope and returns nothing for obsolete concepts. The chain is shown as "Flexril" → Flexeril (matched via RxNorm) → cyclobenzaprine → CYCLOBENZAPRINE HYDROCHLORIDE. Alternative: hand-type a Flexeril entry, which Section 3.4 forbids without a cited source.
7. **Adderall IR is an ANDA product.** The Adderall label (set_id f22635fe-821d-4cde-aa12-419f8b53db81) lists `application_number` ANDA040422, so the T09 rule as written does not assign Brand Name Product even though the brand name differs from the generic name. Choice: follow the rule as written. Recorded so the user can decide whether the rule needs a note.
8. **Layout additions.** Section 9.4 lists the modules; the build needs a few more to keep I/O and logic apart: `collect/manifest.py` (pure manifest parsing), `collect/stream_decode.py` (pure incremental JSON array decoding, so a 1 GB partition is never loaded whole), `collect/partition_reader.py` (zip I/O), and one `run.py` per package holding the job functions that `cli.py` dispatches to, since `cli.py` may hold no logic. Reason recorded in `phase0_audit.md`.
9. **DailyMed URL pattern is undocumented.** The `drugInfo.cfm?setid=` page works live and is what DailyMed itself links to, but no official support page states the pattern. Choice: use it, and record that it was verified by a live request rather than documentation.
10. **openFDA Authentication page wording.** The page says a key "is required" but lists no-key limits and key-less calls succeed. Choice: the build uses no key for bulk downloads and fixtures; a key can be added later by parameter if the daily limit matters.

## Phase 2

11. **RxNorm fallback needs an internet call per unresolved name.** Section 3.3 says fall back to RxNorm "only if the local dictionary fails." The `resolve` CLI command calls RxNorm live by default and accepts `--no-rxnorm` to skip it for fully offline runs; tests never call the network and instead serve saved fixture responses through the same `fetch` function signature.
12. **Base-ingredient map build time.** Mapping every one of the collection's 2,551 distinct substances through RxNorm's `findRxcuiByString` and `getRelatedByType`, one call each and capped at 20 requests per second per NLM's terms, takes on the order of tens of minutes for a full build. The job checkpoints its cache every 100 substances so a weekly rebuild can resume instead of restarting.
13. **`openfda.brand_name` provenance is unverifiable.** Section 4.3 states it is copied from the NDC Directory proprietary name; no official openFDA page confirms this. Recorded in `VERIFIED_FACTS.md`; the tool does not depend on this claim for any logic, only for a footnote if the README mentions it.

## Phase 3

14. **T04's drug-group column identification.** FDA adverse-reaction tables use `rowspan` on the reaction-name header cell, which the stdlib `html.parser`-based table reader does not reconstruct. The rule reads column identity from the table's first row only (the row with the full column count), treats any non-empty column after the first whose header does not say "placebo," "vehicle," or "control" as a drug-group column, and reads each cell's percentage from a trailing parenthesized number or an explicit `%` sign. Prose `adverse_reactions` sentences are read the same way: the first percentage in a sentence counts as the drug rate. This is a heuristic column reader, not a full table-structure parser.
15. **T03's positive and negative cue lists are not exhaustive.** Appendix C's "Assign when" and "Do not assign when" clauses are implemented as regular expressions over `pediatric_use` and `indications_and_usage` sentences (an established-safety-and-effectiveness pattern and an indicated-for-pediatric pattern, excluded by a not-established or contraindicated-in-children pattern). A label that states either idea in unusual wording could be missed (false negative, which the term's own "missing means omit" rule already tolerates) or, less likely, matched by an atypical phrasing that resembles the positive pattern.
16. **T17's class and drug detection is a heuristic, not a full extractor.** Section 6 item 8 asks the rule to also extract named drugs and classes into a structured list; `extract_class_mentions` does this only for gazetteer hits, built from the collection's own `pharm_class_epc`/`pharm_class_moa` values and the FDA enzyme table's inhibitor, inducer, and substrate names (never typed from memory). A generic class-word signal (`inhibitor`, `inducer`, `antagonist`, `agonist`, `MAOI`) is treated as evidence of a class reference even without a gazetteer hit, since the enzyme table and the collection's classes cannot list every possible class phrase. The rule excludes a sentence that only restates the label's own brand, generic, or substance name, and excludes self-referential phrasing such as "in common with other X" or "known X sensitivity" unless a genuine combination signal (concomitant, concurrent, co-administered, combined, MAOI, "taking, or within N days") is also present. Manual review of a 15-sentence random sample after this fix found it overwhelmingly correct (confirmed MAOI, CYP3A4 inhibitor/inducer, and named-drug contraindications) with a small residual of sentences that name the label's own pharmacologic class in words rather than its own product name (for example an ACE inhibitor's angioedema-history contraindication, which mentions "ACE inhibitor" as a class descriptor of itself). Section 5 already frames every interaction-risk term and tier as a heuristic; this residual imprecision is disclosed here rather than chased to zero.
17. **T06/T12's dose-change cue is broad by design.** Appendix C excludes "avoid" and "contraindicated" statements that give no dose, but keeps "dosage adjustment ... is necessary" statements that give no numeric dose either. The rule therefore accepts a match on an explicit "dosage/dose adjustment" phrase alone (as gabapentin's and Entresto's labels use), a numeric `mg` value, or a specific verb (reduce, lower, decrease, extend, increase the interval, titrate), and separately excludes a sentence containing "avoid" or "contraindicat-" unless it also carries one of those same dose-change cues.
